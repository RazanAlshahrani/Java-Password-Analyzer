# Java Password Analyzer

A Java-based cybersecurity project designed to validate password strength, detect common weaknesses, and generate secure password suggestions.

## Project Overview
The application evaluates user-entered passwords based on predefined security requirements and identifies weak or predictable patterns.

## Key Features
- Validates password length (8–12 characters).
- Checks for uppercase and lowercase letters, numbers, and special characters.
- Detects passwords containing the user's email username.
- Identifies predefined weak words and sequential patterns.
- Detects four or more identical consecutive characters.
- Generates secure password suggestions using Java SecureRandom.

## Implementation
The project is developed in Java using NetBeans and consists of four main components:
- **Main:** Handles user input and displays validation results.
- **PasswordValidator:** Checks password structure and email similarity.
- **PasswordWeaknessChecker:** Detects common weak words and predictable patterns.
- **PasswordSuggestion:** Generates alternative passwords that satisfy the implemented requirements.
